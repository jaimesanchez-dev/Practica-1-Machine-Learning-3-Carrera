# 🏦 Predicción de Suscripción a Depósito Bancario

Aplicación web desarrollada en **Python** utilizando **Streamlit** que permite predecir si un cliente bancario contratará un depósito a plazo fijo en función de sus características demográficas, financieras y de historial de contacto.

---

## 🚀 Características

* **Formulario Interactivo:** Entrada intuitiva de variables del cliente (edad, tipo de trabajo, balance anual, estado civil, canales de contacto, etc.)[cite: 3].
* **Inferencia en Tiempo Real:** Carga optimizada del modelo de Machine Learning empaquetado (`final_model.pkl`) con caché en memoria[cite: 3].
* **Estimación de Probabilidad:** Muestra la probabilidad asociada a la predicción si el modelo subyacente soporta probabilidades (`predict_proba`)[cite: 3].
* **Sección de Verificación:** Incluye comprobaciones integradas con dos perfiles fijos (cliente favorable y desfavorable) para validar la consistencia del modelo frente al entorno de desarrollo/notebooks[cite: 3].

---

## 🛠️ Tecnologías Utilizadas

* **Python 3.x**
* **Streamlit:** Interfaz de usuario y componentes web interactivos[cite: 3].
* **Pandas & NumPy:** Estructuración y manipulación de datos de entrada[cite: 3].
* **Scikit-Learn / Pickle:** Carga y ejecución del pipeline/modelo entrenado[cite: 3].
